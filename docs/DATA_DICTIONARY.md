# VANRA Data Dictionary
**Visual AI Network for Rights Administration**
*Database Schema & Field Definitions (`data/vanra.db`)*

---

## 1. Table: `claims`
Stores the master registry of individual and community forest rights claims.

| Field Name | Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `claim_id` | TEXT | PRIMARY KEY | Unique alphanumeric identifier (e.g., `FRA-MP-00482`). |
| `state` | TEXT | NOT NULL | State name (e.g., `Madhya Pradesh`, `Maharashtra`, `Odisha`). |
| `district` | TEXT | NOT NULL | District name (e.g., `Mandla`, `Gadchiroli`, `Koraput`). |
| `block` | TEXT | NOT NULL | Administrative block / tehsil. |
| `village` | TEXT | NOT NULL | Village name / Gram Sabha jurisdiction. |
| `claim_type` | TEXT | NOT NULL | `Individual (IFR)` or `Community (CFR / CR)`. |
| `status` | TEXT | NOT NULL | Current status (`Approved`, `Under Review`, `Pending`, `Rejected`, `Remanded`). |
| `committee_stage` | TEXT | NOT NULL | Stage in workflow (`Gram Sabha`, `Verification`, `SDLC Review`, `District Review`). |
| `claim_date` | TEXT | NOT NULL | ISO 8601 date when claim was originally submitted. |
| `verification_date` | TEXT | NULLABLE | Date of completed or scheduled joint field verification. |
| `claimed_area` | REAL | NOT NULL | Land acreage claimed by the applicant in hectares. |
| `recorded_area` | REAL | NULLABLE | Acreage recorded in revenue cadastral survey in hectares. |
| `record_status` | TEXT | NOT NULL | `Verified`, `Under Review`, or `Discrepancy Found`. |
| `latitude` | REAL | NOT NULL | Geospatial centroid latitude in decimal degrees. |
| `longitude` | REAL | NOT NULL | Geospatial centroid longitude in decimal degrees. |
| `processing_days` | INTEGER | NOT NULL | Cumulative elapsed days since submission. |
| `risk_score` | INTEGER | NOT NULL | Composite algorithmic risk index from 0 to 100. |
| `risk_level` | TEXT | NOT NULL | Qualitative tier (`Critical`, `High`, `Medium`, `Low`, `Minimal`). |
| `anomaly_reasons` | TEXT | NULLABLE | JSON array of flagged anomaly descriptors. |
| `forest_zone` | TEXT | NOT NULL | Forest category (`Protected Forest`, `Reserve Forest`, `Wildlife Corridor`). |
| `land_type` | TEXT | NOT NULL | Land classification (`Forest Land`, `Revenue Forest`, `Unclassed Forest`). |

---

## 2. Table: `districts`
Stores district-level aggregates, geospatial coordinates, and health indices.

| Field Name | Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `district_name` | TEXT | PRIMARY KEY | Unique district name. |
| `state_name` | TEXT | NOT NULL | Associated state. |
| `center_lat` | REAL | NOT NULL | Geographical center latitude for map auto-zoom. |
| `center_lng` | REAL | NOT NULL | Geographical center longitude for map auto-zoom. |
| `total_claims` | INTEGER | NOT NULL | Total number of claims registered in district. |
| `approved_claims` | INTEGER | NOT NULL | Number of approved titles granted. |
| `pending_claims` | INTEGER | NOT NULL | Claims currently in progress. |
| `delayed_claims` | INTEGER | NOT NULL | Claims exceeding 180 days in review. |
| `high_risk_claims` | INTEGER | NOT NULL | Claims with risk score >= 65. |
| `mismatches` | INTEGER | NOT NULL | Claims flagged with cadastral area discrepancies. |
| `health_score` | INTEGER | NOT NULL | Implementation Health Index from 0 to 100 (higher = healthier). |
| `risk_level` | TEXT | NOT NULL | District risk rating (`Low`, `Medium`, `High`, `Critical`). |

---

## 3. Table: `anomalies`
Stores granular detected anomalies generated by the rule engine and Isolation Forest.

| Field Name | Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `anomaly_id` | TEXT | PRIMARY KEY | Unique anomaly event identifier. |
| `claim_id` | TEXT | FOREIGN KEY | References `claims.claim_id`. |
| `district` | TEXT | NOT NULL | Associated district. |
| `state` | TEXT | NOT NULL | Associated state. |
| `anomaly_type` | TEXT | NOT NULL | Category: `DELAY`, `RECORD_MISMATCH`, `GEOGRAPHIC_CLUSTER`, `WORKFLOW_BOTTLENECK`, `UNUSUAL_AREA`. |
| `severity` | TEXT | NOT NULL | `high`, `medium`, or `low`. |
| `risk_contribution` | INTEGER | NOT NULL | Points contributed to the parent claim's risk score (5 to 35). |
| `description` | TEXT | NOT NULL | Specific human-readable rationale for the detected flag. |
| `detected_date` | TEXT | NOT NULL | Timestamp when the anomaly was flagged. |

---

## 4. Table: `timeline_events`
Stores historical and active workflow transitions across statutory committees.

| Field Name | Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `event_id` | TEXT | PRIMARY KEY | Unique timeline record identifier. |
| `claim_id` | TEXT | FOREIGN KEY | References `claims.claim_id`. |
| `stage` | TEXT | NOT NULL | Workflow step (`Claim Submitted`, `Field Verification`, `SDLC Review`, `DLC Review`). |
| `status` | TEXT | NOT NULL | `Completed`, `Active`, or `Delayed`. |
| `start_date` | TEXT | NOT NULL | Date entered this workflow stage. |
| `end_date` | TEXT | NULLABLE | Date completed this workflow stage. |
| `duration_days` | INTEGER | NOT NULL | Elapsed days spent in this stage. |
